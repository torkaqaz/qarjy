# Qarjy — семейные финансы

## Запуск

1. Установите Node.js 20.19+ или 22.12+.
2. Откройте папку проекта в терминале.
3. Выполните `npm install`.
4. Выполните `npm run dev` и откройте адрес, показанный в терминале.
5. Для проверки сборки выполните `npm run build`.

## Публикация на Vercel

1. Создайте репозиторий на GitHub и загрузите туда содержимое папки qarjy.
2. Зарегистрируйтесь на vercel.com через GitHub.
3. Нажмите Add New → Project, импортируйте репозиторий.
4. Framework Preset: Vite; Build Command: `npm run build`; Output Directory: `dist`.
5. Нажмите Deploy. Получите адрес вида `имя-проекта.vercel.app`.

## Данные и безопасность

- Данные хранятся в localStorage только текущего браузера. На другом устройстве их не будет.
- Перед очисткой браузера экспортируйте JSON-резервную копию.
- JSON-файл содержит финансовую информацию в открытом виде: храните его безопасно.
- Не вводите номера карт, пароли и банковские реквизиты.
- Вводимые суммы — в тенге. Автоматической синхронизации, курсов валют и обновления кредитов нет.
- Платежи по кредитам и переводы между счетами требуют ручного учёта; не дублируйте их как расходы.
