# Qarjy 2.0

Три вкладки: Общая, Приход, Расход. Категории со смайликами, пункт «Другое», собственные категории, примечания, история операций, экспорт/импорт резервной копии.

## Размещение на GitHub и Vercel

Замените в корне существующего репозитория файлы `index.html`, `main.jsx`, `style.css`, `package.json`, `README.md` на файлы из этого архива. **Не загружайте сам ZIP.**

Vercel: Framework Preset = Vite, Build Command = `npm run build`, Output Directory = `dist`. Новый коммит в main запускает повторную публикацию автоматически.

Локальный запуск: `npm install`, затем `npm run dev`.

## Хранение

Данные хранятся в localStorage конкретного браузера и устройства. Это не облачная синхронизация. Используйте Экспорт для резервного копирования и Импорт для восстановления. Импорт заменяет текущие записи.
